# Menedżer Kontaktów

Aplikacja webowa do zarządzania listą kontaktów — dodawanie, edycja i usuwanie wpisów.
Napisana w czystym JavaScript, budowana bundlerem Webpack.

## Stack

- JavaScript
- Webpack
- HTML5 / CSS3

## Uruchomienie

```bash
npm install
npm start
```

Serwer deweloperski otworzy się automatycznie w przeglądarce.
Build produkcyjny: `npm run build`.
